Desenvolvimento de APIs RESTful e integração de dados para diferentes contextos de negócio, com modelagem relacional e não relacional.

## Atividades

- APIs RESTful para processamento e integração de dados com Python (Django, FastAPI) e Node.js (Express)
- Modelagem de dados em MongoDB e PostgreSQL, com dados estruturados e não estruturados
- Pipelines de dados com CI/CD e Docker
- Frontend em React com foco em visualização de dados
- Levantamento de requisitos, documentação de arquitetura e rituais Agile/Scrum
